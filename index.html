About the Project

CartSense: Smarter Electronics Recommendations

CartSense is a full-stack Machine Learning Operations (MLOps) demonstration project that implements a state-of-the-art hybrid recommendation system for electronics.

Architecture

  • PySpark & ALS: Handles large-scale matrix factorization to compute collaborative filtering scores based on implicit user interactions.
  • Scikit-Learn TF-IDF: Computes content-based similarities between product specifications to solve the cold-start problem.
  • FastAPI & PostgreSQL: A high-performance Python backend serving real-time hybrid recommendations from the database.
  • MLflow & Evidently: Provides robust model versioning, experiment tracking, and real-time data drift monitoring.

The Hybrid Approach

By blending collaborative signals (what users buy) with content signals (what the product is), CartSense achieves a 94.8% Precision@10 score, outperforming either model independently while ensuring high-quality cold-start handling.
